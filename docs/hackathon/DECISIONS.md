Where the code or the environment contradicts `SPEC.md`, the code wins and the deviation is recorded here.

| D7 | 2026-09-25 | Extracted the write paths of `PUT /frames/:id/artwork`, `/motion`, `/dialogue` and `POST /storyboard/apply-edit` into `src/lib/services/frameWrites.ts`. The routes are now thin wrappers, and the Director calls the same functions in-process. | SPEC §1 says "call directly, not over HTTP". One implementation means identical validation and failure semantics for agents over HTTP and for the in-app crew. |
| D8 | 2026-09-25 | **Every shot becomes an animated clip.** The Artist's painting is stored in the project defs as `<pattern id="art-fN">`. The motion spec's scene is one canvas-sized rect filled with it, and tracks on `place.at`/`place.scale` produce a real dolly/pan/tilt (the pattern lives in the group's user space). Motion-mode shots add an Artist-written ambient layer (2D construct shapes + tracks). Painting ids are namespaced per shot (`f3-sky`). If the defs would exceed the 512 KB limit, or the clip fails, the shot is kept as a still, and the trace records why. | This animates vector stills with **zero engine changes**: `construct/`, `motion/` and `svgRenderer.ts` are untouched. Verified with a contact sheet. Honest limit: characters don't articulate inside a shot; motion comes from the camera, the ambient layer and the cuts. |
| D9 | 2026-09-25 | Each run lives inside the SSE request that started it. Cancel = `POST …/cancel` **or** the client disconnecting; both abort the run's signal. An in-memory registry maps runId → AbortController (single instance). | AGENTS.md forbids job queues and polling. A run with no listener would be exactly that kind of background job. |
| D10 | 2026-09-25 | Dialogue (TTS via `writeFrameDialogue` → `resolveVoice`) is recorded **before** the shots are drawn. Each clip lasts max(planned duration, voice end + 0.4 s). | That way the Editor's VOICE_OVERRUN findings don't happen by construction. The Editor still runs `lintStoryboard` and fixes READING_SPEED / JUMP_CUT. |
| D11 | 2026-09-25 | A critic revision replaces the shot only if it scores **higher** than the current version. Otherwise the previous version is kept and the loop stops. Both scores and both images are stored as steps. | "Critic uplift" can then never be negative by accident, and the before/after pair is always real. |
| D12 | 2026-09-25 | Docker image is based on `ubuntu:24.04`, with Node 22 copied from `node:22-bookworm-slim`. It ships ffmpeg 6.1 + espeak-ng, runs `prisma migrate deploy` on boot, and uses the volume `/data` (`DATABASE_URL=file:/data/storyboard.db`, `STORAGE_ROOT=/data/storage`). Secrets are never baked in. | The ffmpeg/espeak versions match the ones the test suite verified. The image was built and booted end to end in the sandbox: gate, unlock, SSE run with the mock crew, MP4 assembled (8.5 s). That build needed a throwaway variant trusting the sandbox TLS-inspection CA and proxy; the committed Dockerfile has none of that. |

Translating the legacy panels is out of scope, and the Director is where the English copy matters. |
| D14 | 2026-09-26 | **Model ids verified live** with `GET /v1/models` (evidence `evidence/models-2026-09-26.json`): Director = `nvidia/Nemotron-3-Ultra-550b-a55b`, Artist/Cast = `nvidia/nemotron-3-super-120b-a12b`, Critic (text) and Editor = `nvidia/NVIDIA-Nemotron-3-Nano-30B-A3B`. D3's "unverified" status is closed. | The live smoke (`evidence/smoke-2026-09-26T00-15-37-541Z.json`) shows `json_schema` output working on all three tiers on the first attempt (0.4–0.7 s for a tiny call). |
| D15 | 2026-09-26 | **There is no Nemotron Omni / vision Nemotron on Token Factory**, so the Visual Critic runs in **TEXT mode** by default: Nano reads the SVG, render statistics and the engine's measured ENGINE CHECKS. The vision path stays implemented and switches on when `NEMOTRON_VISION_MODEL` names an exact listed id. | `evidence/vision-probe-2026-09-26.json`: Nano and Super answer `400 "This model does not support image input"`. Two non-NVIDIA VLMs in the same catalog, `openbmb/MiniCPM-V-4_5` and `google/gemma-3-27b-it`, accepted the same PNG. Whether to enable one of them as the critic is **the owner's call**: it makes the crew better but no longer all-Nemotron. |
| D16 | 2026-09-26 | Live scripts in this cloud sandbox run with `NODE_USE_ENV_PROXY=1` (Node 22 undici `EnvHttpProxyAgent`). There is no code change. | Node's own `fetch` ignores `HTTPS_PROXY` and hits a stale host allowlist (403), while curl through the agent proxy works. It is a sandbox detail only: Railway and ordinary machines need nothing. |
| D17 | 2026-09-26 | **Render-measured quality gates** in `validateDrawing`/`validateLibrary`: (1) every character of the shot is visible, and the largest one's **visible height measured by pixel difference** meets the shot type's minimum (close-up 75 %, medium 45 %, wide 25 %, else 30 %); (2) night scenes (`NIGHT_WORDS`) render with mean brightness ≤ 120; (3) set symbols cover ≥ 97 % of the frame; (4) minimum detail (set 15 shapes, character 12, prop 5) and viewBox aspect per kind. The gates are strict on every attempt except the last, which is lenient so a shot is never lost. Their measurements go to the text critic as authoritative facts. | Real runs 1–4 showed tiny characters (scale transforms bypassed an attribute check), bright "night" scenes, non-covering sets, and a Nano critic that misread prose size rules ("70 % exceeds the 30 % limit" → 6/10 → a harmful revision). Measuring the render is immune to transforms and nesting, and stating the result stops the critic from re-judging it. |
| D18 | 2026-09-26 | **The cast library is accepted per symbol.** A repair turn redraws only the members that failed (the prompt names the kept ones), and gradients travel with their symbol (`neededExtras`, collisions renamed). A member still failing after the last repair uses its best attempt: sets get `preserveAspectRatio="xMidYMid slice"` plus a backing rect in their first colour, so they always cover the frame. The prompt also carries one hand-made style reference (a character and a set) that is test-enforced to pass the same gates. | In run 4 a lenient last attempt replaced a mostly-good library with a crude one, and in run 5 a repair dropped symbols it had already drawn. Keeping accepted work makes repairs cheaper and never regressive. |
| D19 | 2026-09-26 | Ambient tracks are normalised deterministically before `motionSpecSchema`: `#rrggbbaa` → `#rrggbb`, and a track-level `ease` is copied onto keys that lack one. | These were the two most frequent ambient-layer rejections from Super in real runs. The fixes are unambiguous, so a repair call is wasted on them. |
| D20 | 2026-09-26 | **Shots are drawn in parallel** (`DIRECTOR_CONCURRENCY`, default 3, max 6) with a bounded pool that stops scheduling on the first error. Commits (shared defs update + clip render) are serialised per project. | Real Super calls take 20–60 s, so a sequential 8-shot film exceeds 10 minutes. Cost is unchanged; the SSE stream still reports every step. The per-project lock prevents an older defs write from dropping a newer shot's `art-fN` pattern mid-render. |
| D21 | 2026-09-26 | `artPattern` rewrites `opacity` on basic shapes to the equivalent `fill-opacity`/`stroke-opacity`, and the prompts ask for `fill-opacity`. | Found in real run 6: librsvg renders `opacity` through an offscreen layer that is clipped to the **unscaled** canvas inside a pattern. Once the camera zooms past ~1.05, a night overlay stops short of the right and bottom edges, leaving a visible bright strip. The fix is a render regression test (`tests/director.test.ts`). `<g opacity>`/`<use opacity>` keep their layer, and the prompt steers away from them. |
| D22 | 2026-09-26 | **Human characters come from a parametric kit (`dollKit.ts`).** The Cast (Super) writes a small spec per human (`age, build, skin, hairStyle, hairColor, top, topColor, bottom, accent, accessories`), and the engine draws a connected, proportioned `<symbol>` from it. Animals, robots, creatures, sets and props are still drawn by Super. Drawn characters must pass a new **"one connected shape"** gate (`opaquePieces` on the render). | In the first hosted showcase run, drawn people had heads floating off their bodies and one shot failed outright. Prose rules and size gates fix composition, not anatomy. The kit follows the repo's own principle, "the model writes specs, the deterministic engine draws" (like `construct` `parts: figure`). It is consistent by construction, costs ~150 output tokens per character instead of ~2 000, and every kit combination is test-enforced to pass the sanitizer and all library gates. Trade-off: human characters share one flat-illustration style. |
| D23 | 2026-09-26 | Live scripts (showcase, bench) **retry a run once** when its SSE stream drops. The bench resumes from `eval/runs.jsonl`. The step costs streamed before a drop are still written to the spend ledger. | Two streams dropped at the same second through the sandbox's egress tunnel ("other side closed"). By design (D9) a disconnect cancels the run server-side, so a retry is the only way to finish. It never falls back to orphan background runs. |
