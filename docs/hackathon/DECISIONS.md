# Decisions & spec deviations — Storyboard Studio Director

Where the code or the environment contradicts `SPEC.md`, the code wins and the deviation is recorded here.

| # | Date | Decision | Why |
|---|---|---|---|
| D1 | 2026-09-25 | Work happens on the harness-designated branch `claude/gracious-ritchie-a739ft`, not `feat/nemotron-director`. The PR to `main` comes from that branch. | The cloud session is bound to that branch for pushes. The owner can rename the branch at merge time. |
| D2 | 2026-09-25 | `sanitizeSvg(fragment, kind)` returns `void` and **throws** `AppError("ARTWORK_INVALID", message, hint)`. SPEC §1 says it "returns hints". The Director catches the AppError and passes `message — hint` back to the Artist as repair feedback. | The code wins. `svgRenderer.ts` stays untouched (security-critical). |
| D3 | 2026-09-25 | The model IDs are **environment-configurable** (`NEMOTRON_{STRONG,MID,FAST,VISION}_MODEL`), with defaults taken from third-party listings of the Token Factory catalog. `npm run director:models` (`GET /v1/models`) must confirm them before the first live run. | This session could not reach `api.tokenfactory.nebius.com` or the docs host (egress policy returns 403), so `GET /v1/models` could not run. The IDs are listed as Unverified in STATUS.md. |
| D4 | 2026-09-25 | Request format: OpenAI-compatible `POST {base}/chat/completions`, with images sent as `image_url` content parts (base64 `data:` URLs). Reasoning is turned off with `chat_template_kwargs: {enable_thinking: false}` for direct-output calls (critic, editor, repair). | Taken from Nebius's own public repository `nebius/nebius-physical-ai` (docs/workbench/token-factory-deprecation-verification.md, verified live 2026-09-04/05). It links the official "vision-capabilities" and "create-chat-completion" API pages, which were unreachable from here. |
| D5 | 2026-09-25 | Tavily is called with plain `fetch`: `POST https://api.tavily.com/search` and `/extract`, auth `Authorization: Bearer <key>`, body `{query, search_depth, max_results, include_answer…}` / `{urls, extract_depth, format}`. A result is `{title, url, content, score}` and an extract result is `{url, raw_content}`. | Read from the official client `tavily-ai/tavily-python` (`tavily/tavily.py`, README). docs.tavily.com was unreachable. No SDK dependency. |
| D6 | 2026-09-25 | The baseline tags `pre-hackathon-baseline` (c9093a3) and `director-spec-baseline` (09f3590) exist locally, but the push was refused: the git proxy only accepts the session branch. Owner action: `git push origin pre-hackathon-baseline director-spec-baseline`. | Environment restriction. |
| D7 | 2026-09-25 | Extracted the write paths of `PUT /frames/:id/artwork`, `/motion`, `/dialogue` and `POST /storyboard/apply-edit` into `src/lib/services/frameWrites.ts`. The routes are now thin wrappers, and the Director calls the same functions in-process. | SPEC §1 says "call directly, not over HTTP". One implementation means identical validation and failure semantics for agents over HTTP and for the in-app crew. |
| D8 | 2026-09-25 | **Every shot becomes an animated clip.** The Artist's painting is stored in the project defs as `<pattern id="art-fN">`. The motion spec's scene is one canvas-sized rect filled with it, and tracks on `place.at`/`place.scale` produce a real dolly/pan/tilt (the pattern lives in the group's user space). Motion-mode shots add an Artist-written ambient layer (2D construct shapes + tracks). Painting ids are namespaced per shot (`f3-sky`). If the defs would exceed the 512 KB limit, or the clip fails, the shot is kept as a still, and the trace records why. | This animates vector stills with **zero engine changes**: `construct/`, `motion/` and `svgRenderer.ts` are untouched. Verified with a contact sheet. Honest limit: characters don't articulate inside a shot; motion comes from the camera, the ambient layer and the cuts. |
| D9 | 2026-09-25 | Each run lives inside the SSE request that started it. Cancel = `POST …/cancel` **or** the client disconnecting; both abort the run's signal. An in-memory registry maps runId → AbortController (single instance). | AGENTS.md forbids job queues and polling. A run with no listener would be exactly that kind of background job. |
| D10 | 2026-09-25 | Dialogue (TTS via `writeFrameDialogue` → `resolveVoice`) is recorded **before** the shots are drawn. Each clip lasts max(planned duration, voice end + 0.4 s). | That way the Editor's VOICE_OVERRUN findings don't happen by construction. The Editor still runs `lintStoryboard` and fixes READING_SPEED / JUMP_CUT. |
| D11 | 2026-09-25 | A critic revision replaces the shot only if it scores **higher** than the current version. Otherwise the previous version is kept and the loop stops. Both scores and both images are stored as steps. | "Critic uplift" can then never be negative by accident, and the before/after pair is always real. |
